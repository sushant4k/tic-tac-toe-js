# Tic Tac Toe Game

## Preview
![Game Preview](screenshot(2).png)

A fully functional Tic Tac Toe web game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Automatic result calculation
- Win, lose, and draw detection
- Restart game functionality

## Live Demo
- https://sushant4k.github.io/tic-tac-toe-js/

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was built to practice JavaScript logic, DOM manipulation, and event handling.
